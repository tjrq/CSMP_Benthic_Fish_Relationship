"dataprep_pred" contains the code for extracting data from a main predator database that is not shared in this folder as another colleague is working on this data. I then combined my own herbivore fish data with this predator data to conduct my analysis on the relationship between predator and herbivore abundance. 

"pred_fits" contains model fits for fitted glmm models, with model outputs saved in the folder "Model". Model interpretation and figure generation are in "pred_results". 

All qmd versions are refactored for ease of code interpretation. This is the only major change from previous versions.
