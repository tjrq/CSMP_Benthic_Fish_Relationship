This folder contains R code for extracting herbivore data from a metadata. The metadata is not shared as other colleagues are currently working on these for their own respective works. The extracted data are extracted and are within this folder. 

The names and the data content within each csv file are:

relationship_fish_ab_ben.csv - contains data on fish abundance and benthic cover

relationship_fish_sp_ben.csv - contains data on fish richness and benthic cover

db_benthic.csv - contains data on benthic cover
